ദ്ദി(ᵔᗜᵔ) Coffee Shop Project 

This project is a frontend web application for a coffee shop, built with HTML, CSS, and JavaScript. It showcases a visually appealing, responsive, and interactive UI for coffee lovers.


🚀 Project Features

Modern coffee shop homepage design

Fully responsive layout (mobile, tablet, desktop)

Interactive menu items with JavaScript (hover effects, add to cart animations)

Header, Banner, Menu section, and Footer redesign

Custom CSS styling with hover effects and animations

Highlighted coffee products with images, descriptions, and JS-powered interactivity


🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)

Flexbox & CSS Grid

Responsive Design

CSS Hover & Animations
